# How to use Schemes + Policies in blog drafts

1. Follow `Writing/bluestone-blog-master-prompt-v5.md` (v4 kept as archive).
2. If the topic touches buying confidence, gold saving, exchange, or installments → open:
   - `Schemes/schemes-cheat-sheet.md`
   - `Policies/policies-cheat-sheet.md`
3. Add **1 scheme CTA** and/or **1 trust CTA** with live links (not bare claims).
4. Put every % / fee / eligibility line on the **Manual Fact-Check List**.
5. Pass `Writing/Blog-SEO-AEO-GEO-Checklist-v2.md` before publish (v1 PDF kept as archive).
6. For AEO: keep scheme/policy facts in short, citable paragraphs (SGE playbook in `GEO/`).
7. For festive wishes: follow v5 festive playbook; mirror CaratLane section coverage, not wording.
8. Supporting keywords → H2 labels / FAQ questions only (see writer notes in checklist v2).
