## Article OS
Follow `Writing/ARTICLE_WORKFLOW.md` for every post (canonical). Draft with Master Prompt v5 + Checklist v2.

- Images: Type 1 raw / Type 2 AI product / Type 3 AI concept under workspace `ProductImages/`
- Carousel mid-article (Type 2); visible FAQs required; no em/en dashes / no `word - word`
- H2s: volume-backed first; competitor-parity buckets lower
- claude-seo = optional QA only, not drafting
- Type 3 visual guide: `HIGGSFIELD_IMAGE_GENERATION.md` (Higgsfield MCP `nano_banana_pro`; Magnific retired)
