## 1. Shipping & Returns
**Source:** shipping-return.html

### Free shipping
- Free delivery/shipping on all items **within India**
- Transit insurance: goods insured until they reach the customer

### 30-day money back
- 100% refund to BlueStone account after QC
- **Not applicable on:** Solitaires above INR 3 lakh, Coins, Customized orders
- Free return shipping within India under this policy
- Refund timing: ~2–3 working days after warehouse QC
- Refund types:
  - **Blue Cash** → can refund to payment source / bank
  - **Blue Credits** → future purchase only (not encashable)
  - Voucher/gift card → per that voucher’s T&Cs

### High-value return pickup
- Product value **≥ Rs 35,000** via 3PL: customer gets tamper-proof packet first, seals jewellery, then pickup
- Always collect pickup acknowledgement

### Support
- cs@BlueStone.com · 18004190066 · 9 am–10 pm, 7 days

**Blog use:** Gift guides, first-jewellery buyers, “buy online jewellery safely,” festival gifts.

## 2. Lifetime Exchange & Buy-Back (LTE / LBB)
**Source:** shipping-return.html#lifetime-exchange

| Topic | Fact |
|---|---|
| Availability | All purchases* made from BlueStone **within India**, after 30-day return window ends |
| How | Store handover **or** online request |
| Valuation | Current market value on day request is raised |
| Online fee | **₹500** shipping/handling if initiated online; **₹0** if handed at store |
| Discounts/gifts | Equivalent value deducted (or gift returned) |
| Missing solitaire cert | Standard deduction **₹3,500**/certificate (may be higher for larger stones) |
| Approval window | Customer has **15 days** to accept/reject valuation on Order History |

### Lifetime Exchange
- Value loaded as **Blue Credits** (valid **365 days**)
- Usable on jewellery **except Coins and Solitaires**
- **Cannot encash**

### Lifetime Buy-Back
- Value loaded as **Blue Cash** (valid **365 days**)
- Can purchase anything **or encash**

### Value matrix (summary — verify live table)

| Category | Exchange | Buy-Back |
|---|---|---|
| Diamond & gemstone jewellery | 100% gold/platinum + 100% diamond/gemstone (current rate) | 100% gold/platinum + **90%** diamond/gemstone |
| Plain gold / platinum | 100% metal | 100% metal |
| Coins | 100% gold/silver | 100% gold/silver |
| Solitaire (≤ INR 5L) | 100% metal + 100% other stones + **90%** solitaire | 100% metal + 90% other stones + **80%** solitaire |
| Solitaire (> INR 5L) | (see live policy — listing / market purchase path) | Same note |

### Extra notes
- Products not bought from BlueStone Stores / bluestone.com / App: **+5%** deduction
- Bought from non-BlueStone offline stores: **not eligible**

**Blog use:** Trust sections, “why buy from BlueStone,” diamond buying guides, wedding jewellery confidence.

## Do-not list (policies)
- Do not promise “lifetime free exchange with zero deductions” — values & fees apply
- Do not say 30-day returns cover all solitaires / coins / custom
- Do not invent Blue Cash vs Blue Credits rules
- Do not paraphrase Privacy beyond “we protect your data; see Privacy Policy” unless the article is specifically about privacy
